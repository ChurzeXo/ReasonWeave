# Requirements

> 项目级需求（不针对单个 feature）。feature 级需求写在 `specs/NNN-*/spec.md`。
> 采用 EARS 风格（AEF §10.3）：每条需求可判定、可验收。

## 需求格式

```
REQ-<域>-<编号>  <标题>
 WHILE <状态> / IF <条件> / WHEN <触发> / WHERE <环境>
 <系统应……>
 验收：<怎么算通过>
 优先级：P0 / P1 / P2
```

## 示例

### REQ-AUTH-001 未登录不可读私有内容
WHILE 用户未登录，系统 SHALL 拒绝访问私有内容并返回 401。
验收：未登录请求私有端点返回 401，且不泄露内容长度。
优先级：P0
