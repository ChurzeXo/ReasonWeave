# Evidence

收尾证据存放处。**只放收尾报告引用到的东西**，不要变成垃圾场。

## 命名

```
evidence/
└── <feature-id>/          ← 与 specs/NNN-* 对应
    ├── build.log          E2 构建日志（关键片段即可）
    ├── test-report.xml    E3 测试报告
    ├── screenshot-*.png   E4 运行截图
    └── acceptance.md      E5 逐条验收确认
```

## 规则

1. **E0（只有口头声称）不许存**——收尾报告里也不许出现。
2. **证据时间戳必须晚于最后一次改动**。改完代码还贴之前的日志 = 过期证据。
3. 命令输出类可以只在收尾报告里贴关键片段 + 指向完整日志的路径。
4. 截图/录屏必须能打开验证（不要贴失效链接）。
5. 级别要求见 playbook `docs/11-evidence.md` §2：
   - 常规 feature：≥ E2 + E3
   - 改 UI/交互：必须 E4
   - 跨 Unit / 架构级：必须 E5

## 收尾报告引用格式

```markdown
| 改动 | 完成 | 证据 |
|---|---|---|
| T001 内容缓存 | ✅ | E3 `evidence/002/test-report.xml` (42 passed) |
| T006 迁移脚本 | ⚠️ 部分 | E2 build.log；e2e 未跑，已记 B-011 |
```

**失败/跳过的项必须如实列出。** 只贴通过的 = 选择性取证。
