- **要做什么**：
  阻断过程噪音，在 Handoff 核心定义规范的三级事件中断总线：
  1. **静默执行层**：Agent 执行阶段的所有中间过程日志、分析碎碎念重定向写入 `.handoffs/.logs/<id>.log`，主控制台只维持极简进度状态；
  2. **中断分类器**：
     - **绿灯（静默）**：工具调用、单测通过、平息等待中 → 零打扰；
     - **黄灯（交付）**：工单完成终态 `baton deliver` 并通过平息窗口 → 触发桌面级系统通知；
     - **红灯（阻断）**：测试重试超限、环境崩溃、权限缺失 → 触发告警中断，呼叫人类介入。
- **为什么没做 / 卡在哪**：
  缺少标准的中断判定状态机，部分 Agent 习惯高频打印过程状态造成告警疲劳。
- **重开会话条件 / 谁拍板**：
  在长时间运行场景（如 10 分钟以上的代码重构）中，人类注意力打扰次数降至 ≤1 次（仅终态交付通知）。
